## 10.2 The consistency method (read this first, it's the whole trick)

1. **Lock the master plate (KF00) first.** Everything else is an *edit* of it, so the car, house, lens and light never drift.
2. For every later keyframe, attach as references: **(1) the previous keyframe, (2) KF00, (3) DETAILER-REF** when a person appears, and start the prompt with the **EDIT LOCK** sentence below.
3. Generate keyframes **in order** (KF01 from KF00, KF02 from KF01…). If a keyframe drifts (car shape, wheel design, window frames), regenerate it before moving on, because drift compounds.
4. Clips use **start + end frame**, so they're just the in-between motion. Keep the camera **locked off** (tripod) unless the segment is a designated camera move.
5. If a camera-move clip (S05 push-in, S08 pull-back) looks warpy, try the **reverse trick**: generate the opposite move (e.g. S08 as a push-in from KF08 to KF07) and set `"reverse": true` in `assets-src/segments.json`. Push-ins are usually cleaner.
6. Download originals at full resolution (PNG for images, MP4 for clips) and name them exactly as listed.
